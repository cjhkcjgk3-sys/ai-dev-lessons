# 重新设计模板

同一个问题修到第 3 次还没好，必须停手，不准再打补丁，发这份等用户确认。

```
【重新设计】
问题：
前几次怎么修的、为什么失败：
- 第 1 次：
- 第 2 次：
- 第 3 次：
根本原因（已知、假设与尚未确认的部分）：
旧方案为什么不能继续：
新方案：
用户预期效果与验收（含关联回归）：
需要用户确认的地方：
等你确认后再继续。
```

- “同一个问题”按用户可见的未达成目标/同一类症状与历史关联判断；换模型、会话、文件、分支或小改症状不清零。已有证据的失败原因与待验证假设分开写，不继续盲目试错。
- 新方案涉及布局、交互或数据格式时，同时满足[方案确认](方案确认.md)。
