# 大问题记录模板

影响使用、反复出现、或涉及数据安全的问题，按这个格式写完整。

```
### [大] 底栏被挤出屏幕
出错模型：Gemini　发现者：用户　状态：未解决
- 现象：用户看到了什么（尽量用用户原话）
- 原因：代码或流程上为什么会这样
- 证据：提交链接、文件:行号、用户原话
- 解决方法：怎么改的；没改就写现在的状况
- 预防措施：以后怎么避免
- 归类：通用 / 专门
```

- **出错模型**按提交署名填，可写多个，不知道写“未知”。
- **发现者**：用户／模型（写明哪个）／未知。用来统计有多少问题要靠用户发现。
- **状态**：未解决／已修未实机验证／已实机验证。修好后回来更新。
- **归类**为通用的，交到 ai-dev-lessons `待审/`，插件仓库只留一行链接。
