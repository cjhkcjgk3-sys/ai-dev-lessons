# 宿主与多端适配速查

相关项目默认 SillyTavern 1.19、SillyDroid Android WebView、桌面浏览器，实际版本以项目为准。以下为可追溯的历史线索和待核验方向，不宣称当前版本均已真机通过。宿主、系统或浏览器升级及行为改变时复核。

| 场景 | 线索或验证方向 | 依据和状态 |
| --- | --- | --- |
| WebView 视口与输入法切换 | 历史案例记录 visualViewport 初始或切换时可能返回过小高度；核对有效视口、回退和容量，不照搬历史阈值 | [旧案例](../正式/cases/世界书更新器.md)、[旧提交](https://github.com/cjhkcjgk3-sys/st-worldbook-updater/commit/d722a8d)；未复测 |
| 主操作与退出可达 | 检查默认视口，不能先自动滚动到按钮再宣布可见 | [WB-02、WB-24](../正式/cases/世界书更新器.md)；模拟与实机分开 |
| 拖拽、触屏、鼠标 | 核对目标设备手势、取消、焦点、滚动及独立工作区容量，不规定宿主统一事件 API | [历史案例](../正式/cases/世界书更新器.md)；具体事件待当前源码核验 |
| 插件加载、卸载、切聊天与监听 | 先查宿主当前生命周期及公开接口，再测试注册/注销、反复启停和迟到响应 | [方法12](../正式/领域经验/软件工程/方法-12.md)；具体钩子待核验 |
| 模拟浏览器与真实宿主 | 无头浏览器加模拟接口不能当成真实酒馆、真实手机实测 | [WB-26](../正式/cases/世界书更新器.md) |

新增知识注明具体版本、环境、证据和日期。手机诊断参见[方法17](../正式/领域经验/软件工程/方法-17.md)。
