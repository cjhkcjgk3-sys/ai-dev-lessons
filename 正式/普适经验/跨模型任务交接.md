# HA-02｜跨会话与跨模型交接

适用范围：长任务、阶段转换、跨会话或跨模型接力  
性质：指导原则或方法论，按实际适用条件采用。  
状态：正式；用户授权综合收录，具体措辞由 GPT 整理；未声称逐项实测或其他模型认证。  
来源：GPT 交接待审建议与其他模型交接协议建议。  
验证：GPT｜逻辑复核（整理者自审，非独立复核）｜通过｜2026-11-28｜逻辑、适用边界及与现行规则的关系，不含实测｜同次提交正文｜[本轮整合记录](../../整理记录/2026-11-28-多模型建议整合记录.md)。

交接传递当前有效工作状态、决策及证据，而非完整聊天或进度百分比。保留已确认目标与授权、关键决定及原因、被否定路线及取舍、已完成工作与证据、未验证假设、卡点、实际版本/提交、下一步入口。涉及反复修复时保留累计次数。已确定约束不得擅自推翻，但可在新证据和授权下修订。

用[任务交接摘要](../../模板/任务交接摘要.md)或项目现有文档保存必要信息，不每轮写长报告。接手者先核对实际项目状态、最新用户要求与适用验证标记，继承有效成果，只查变化和缺口。验收：新 Agent 能定位决定、证据、未决和接手步骤，不重做已充分完成的调查，不盲信过期状态。
