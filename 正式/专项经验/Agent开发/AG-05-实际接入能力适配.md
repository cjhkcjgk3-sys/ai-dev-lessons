# AG-05｜模型能力按实际接入链判断

适用范围：开发 LLM 驱动、可调用工具或自主执行任务的 Agent 应用  
性质：指导原则或方法论，按实际适用条件采用。  
状态：正式；用户授权综合收录，具体措辞由 GPT 整理；未声称逐项实测或其他模型认证。  
来源：GPT 前次评估的额外建议。  
验证：GPT｜逻辑复核（整理者自审，非独立复核）｜通过｜2026-11-28｜逻辑、适用边界及与现行规则的关系，不含实测｜同次提交正文｜[本轮整合记录](../../../整理记录/2026-11-28-多模型建议整合记录.md)。

同一模型在不同 API、代理、宿主、版本、配置下的图片、工具、联网、流式或结构化输出能力可能不同。依据实际接入链可靠元数据、文档及必要最小探测判断支持范围，不仅依模型名称或永久硬编码名单。注明环境、版本及条件；能力未知或不可用时说明原因并合理降级，不伪造成功。

仅相关功能需要、环境变化或证据不足时探测，避免每轮请求和无关数据外发。验收同名不同接入、拒绝、缺失、换版本与降级。具体服务支持仍需证据。
