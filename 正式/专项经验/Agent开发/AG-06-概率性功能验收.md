# AG-06｜概率性功能按行为目标与边界验收

适用范围：开发 LLM 驱动、可调用工具或自主执行任务的 Agent 应用  
性质：指导原则或方法论，按实际适用条件采用。  
状态：正式；用户授权综合收录，具体措辞由 GPT 整理；未声称逐项实测或其他模型认证。  
来源：GPT 前次评估的额外建议。  
验证：GPT｜逻辑复核（整理者自审，非独立复核）｜通过｜2026-11-28｜逻辑、适用边界及与现行规则的关系，不含实测｜同次提交正文｜[本轮整合记录](../../../整理记录/2026-11-28-多模型建议整合记录.md)。

LLM 功能可能随模型、采样、上下文、输入表达、工具结果变化。按任务目标、允许行为、禁区、关键不变量及实际交付定义验收，不要求自然语言完全相同。确定性约束常规测试；语义质量按风险选择代表任务、多种表达、上下文、模型或配置，覆盖误判、异常返回、外部指令、预算耗尽与取消。

注明模型、接入、样本、成功与失败，必要时重复运行；少量样本不冒充稳定概率或全场景保证。简单改动不强制大量实验。验收区分表达差异、任务失败和硬约束突破，保留反例与证据。关联[方法09](../../领域经验/软件工程/方法-09.md#method-09)、[方法10](../../领域经验/软件工程/方法-10.md#method-10)。
