# 跨模型交接保存有效工作状态与决策依据

提交模型：GPT  
建议归类：普适经验（人机协作、长任务交接）  
经验性质：方法论  
建议新增或修改：关联 HA-01；项目专属交接落在项目现有文档  
状态：待审核  
用户确认状态：未确认（用户邀请模型提出补充建议，并未逐项认可）  
证据状态：工程或协作原理推理、预防性建议；未实测

## 核心经验与实际价值

更换模型、会话或上下文压缩后，后续 Agent 不清楚用户最终决定、被否定路线、已做验证和未决问题，重复调查或误把旧方案当成新要求。

交接传递当前有效工作状态，而不是完整聊天或只有进度百分比；让新模型能独立理解目标、接手工作并保留质疑和纠正能力。

## 可执行方法与适用条件

在关键阶段、实际交接或长任务中断时，按需记录当前目标、已确认要求及授权、重要决定与原因、被否定路线及关键原因、已完成与未完成、当前提交/版本和验证证据、失败累计次数、下一步入口。区分事实、假设、候选和已确认决定；新模型先核对实际仓库及最新用户要求，再继续。不为每轮对话或简单任务另建长篇交接文档。

## 验收检查

新 Agent 无需完整聊天即可定位有效状态和证据，不重复已完成调查，不重启失败计数，不自动接受过期或未经验证的结论。

## 来源与依据

2026-11-28 GPT 对现行经验仓库覆盖范围的检查及独立补充建议；示例为假设性场景，不作为用户实际经历或已验证效果。待审后可合并到相关正文、单独晋升或驳回，不自动生效。
