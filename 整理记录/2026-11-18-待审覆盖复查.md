# 待审覆盖复查（文档检查，不是插件验收）

基线：[05301b1a1de60b990ab3eb82e6c60428da7dcbba](https://github.com/cjhkcjgk3-sys/ai-dev-lessons/tree/05301b1a1de60b990ab3eb82e6c60428da7dcbba/待审) 的 10 条。本轮读了这 10 条、正式区相关 WB/RC 案例，以及本地已有世界书更新器和角色卡问题日志；未重新核对插件当前代码或运行效果。新增经历按用户反馈标识，不推断所属插件、发生时间、修复结果或责任模型。

## 逐条检查

| 条目 | 可执行验收依据 | 本轮处置 |
| --- | --- | --- |
| 01 UI一致性 | 同任务跨入口对照命名、布局、交互、反馈 | 补实际比较步骤，区分一致性与可用性 |
| 02 复用 | 同样例多入口同结果，替换后旧路径失效 | 已有可检查结果，保留 |
| 03 规划 | 目标/范围/关联清单对应操作及预期结果 | 补预算与不满足时取舍，不只写“好用” |
| 04 用户流程 | 常态/折叠/加载/错误退出路径，长文案/缩放空间 | 重写并细分任务、退出、文字、辅助方式检查 |
| 05 输入边界 | 长短名、同名、空值与规模等维度的预期处理 | 已有正常/反例/边界约束，保留 |
| 06 容错 | 正常变体、歧义、冲突、失败恢复与数据不误写 | 已有结果要求，保留 |
| 07 错误假设 | 新反例通过且旧正例、相邻反例不回退 | 已有对照要求，保留 |
| 08 联动 | 各适用入口、预览/执行、状态与最终数据一致 | 已有影响表和结果要求，保留 |
| 09 全流程回归 | 输入与预期/实际结果、设备差异、端到端流程 | 补显式引用 04/11，不能只看默认截图 |
| 10 证据边界 | 版本、环境、已测流程和缺口均可追溯 | 补“已整理材料”不等于“找全所有问题” |
| 11 窗口任务容量 | 最小可用空间、遮挡/焦点/滚动/切换/状态 | 独立新增：不同于 UI 风格或按钮组织的布局验收维度 |

## 范围与余留

- 当前有效候选为 11 条，全部待用户审核；正式区未改，插件未改。
- 新增三种经历均是用户反馈，本轮未核对代码；相关历史案例只是佐证某类风险，不证明新经历属于同一插件。
- 本轮完成的是上述材料的文档覆盖检查，验收条件是建议将来执行的方法，不是已经执行并通过的测试。
- 未穷尽用户全部经历或全部潜在问题；新反馈仍可能暴露需求、设计或验证维度缺口。
